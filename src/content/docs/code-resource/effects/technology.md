<a id="add-tech-bonus"></a>
## `add_tech_bonus`

Выдаёт стране **ограниченный по числу использований бонус к исследованию технологий**. Бонус можно привязать либо к конкретным технологиям через `technology`, либо к категории технологий через `category`.

### Параметры

| Параметр | Что делает |
|---|---|
| `name` | Имя бонуса, используемое в интерфейсе исследования. Необязательно. |
| `bonus` | Бонус к скорости исследования. `0.5` = +50% к исследованию при использовании бонуса, `1.0` = +100%. |
| `uses` | Сколько раз бонус можно использовать. По умолчанию — 1. |
| `ahead_reduction` | Уменьшение штрафа за исследование технологии **раньше срока**. `1` означает полное (100%) снятие штрафа ahead-of-time для применения бонуса. |
| `category` | Категория технологий, на которую распространяется бонус. Можно указать несколько категорий. |
| `technology` | Конкретная технология, на которую распространяется бонус. Можно указать несколько технологий. |

### Бонус на конкретные технологии

Если указать `technology`, бонус доступен только для перечисленных технологий:

```text
add_tech_bonus = {
    name = assembly_bonus
    bonus = 0.5
    uses = 2
    technology = improved_machine_tools
    technology = advanced_machine_tools
    technology = assembly_line_production
}
```

Здесь страна получает **2 использования бонуса +50%**, которые можно потратить на любые две из перечисленных технологий. citeturn0search0

### Бонус на категорию

Вместо списка конкретных технологий можно указать `category`:

```text
add_tech_bonus = {
    name = electronics_bonus
    bonus = 0.5
    uses = 1
    category = electronics
}
```

Такой бонус можно потратить один раз на технологию из категории `electronics`. citeturn0search0turn0search1

### `ahead_reduction`

`ahead_reduction` работает не как дополнительный процент скорости исследования. Он уменьшает **штраф за исследование технологии раньше исторического срока**.

Например:

```text
add_tech_bonus = {
    name = electronics_bonus
    bonus = 0.5
    ahead_reduction = 1
    uses = 1
    category = electronics
}
```

При таком сочетании одно использование бонуса даёт выбор между **+50% к скорости исследования** и **полным (100%) снятием штрафа ahead-of-time** для подходящей технологии. То есть `ahead_reduction` — это отдельная часть исследовательского бонуса, а не постоянный модификатор страны. citeturn0search0turn0search1

Это особенно полезно для эффектов, которые должны дать стране возможность раньше обычного исследовать конкретную технологию или технологическую категорию. Например, в игре встречается отдельный `ahead_reduction` для конкретной технологии и отдельный бонус к категории брони. citeturn0search4

### `bonus` и `ahead_reduction` вместе

Параметры можно указывать в одном `add_tech_bonus`. Они описывают **два типа преимущества одного исследовательского бонуса**, а не постоянные модификаторы страны.

```text
add_tech_bonus = {
    name = tank_development_bonus
    bonus = 1.0
    ahead_reduction = 1
    uses = 1
    category = armor
}
```

Здесь одно использование даёт либо **+100% к скорости исследования**, либо **полное снятие ahead-of-time штрафа** для подходящей технологии. citeturn0search0turn0search7

<a id="category-and-technology"></a>
## `category` и `technology`

`category` выбирает группу технологий, а `technology` — конкретные технологии. Оба параметра поддерживают несколько значений.

Категории исследовательских бонусов определяются игрой в `common/technology_tags/`, а конкретные технологии — в `common/technologies/`. Полный список категорий распишем отдельно. citeturn0search1turn0search3
