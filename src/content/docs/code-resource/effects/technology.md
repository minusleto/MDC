## `add_tech_bonus`

Выдаёт стране **ограниченный по числу использований бонус к исследованию технологий**. Бонус можно привязать либо к конкретным технологиям через `technology`, либо к категории технологий через `category`.

### Параметры

| Параметр | Что делает |
|---|---|
| `name` | Имя бонуса, используемое в интерфейсе исследования. Необязательно. |
| `bonus` | Бонус к скорости исследования. `0.5` = +50% к исследованию при использовании бонуса, `1.0` = +100%. |
| `uses` | Сколько раз бонус можно использовать. Если не задан, используется одно применение. |
| `ahead_reduction` | На сколько лет уменьшается штраф за исследование технологии **раньше срока**. `1` = убрать один год ahead-of-time штрафа при использовании бонуса. |
| `category` | Категория технологий, на которую распространяется бонус. Можно указать несколько категорий. |
| `technology` | Конкретная технология, на которую распространяется бонус. Можно указать несколько технологий. |

### Бонус на конкретные технологии

Если указать `technology`, бонус доступен только для перечисленных технологий:

```text
add_tech_bonus = {
    name = assembly_bonus
    bonus = 0.5
    uses = 2
    technology = improved_machine_tools
    technology = advanced_machine_tools
    technology = assembly_line_production
}
```

Здесь страна получает **2 использования бонуса +50%**, которые можно потратить на любые две из перечисленных технологий.

### Бонус на категорию

Вместо списка конкретных технологий можно указать `category`:

```text
add_tech_bonus = {
    name = electronics_bonus
    bonus = 0.5
    uses = 1
    category = electronics
}
```

Такой бонус можно потратить один раз на технологию из категории `electronics`.

### `ahead_reduction`

`ahead_reduction` работает не как дополнительный процент скорости исследования. Он уменьшает **штраф за исследование технологии раньше исторического срока**.

Например:

```text
add_tech_bonus = {
    name = electronics_bonus
    bonus = 0.5
    ahead_reduction = 1
    uses = 1
    category = electronics
}
```

У этого одного использования есть два возможных преимущества: **+50% к скорости исследования** или **снижение ahead-of-time штрафа на 1 год**. При выборе технологии бонус применяется как соответствующий исследовательский бонус, а не как постоянный модификатор страны.

`ahead_reduction` особенно полезен для эффектов, которые должны позволить стране раньше обычного начать исследование конкретной технологии или технологической категории.

### `bonus` и `ahead_reduction` вместе

Параметры можно указывать в одном `add_tech_bonus`. Это не означает, что страна получает постоянные `+50%` к скорости исследования **и** одновременно постоянное уменьшение штрафа на год. Это параметры одного ограниченного использования исследовательского бонуса.

```text
add_tech_bonus = {
    name = tank_development_bonus
    bonus = 1.0
    ahead_reduction = 1
    uses = 1
    category = armor
}
```

В таком случае одно использование может дать **+100% к скорости исследования** либо использоваться как **снижение ahead-of-time штрафа на 1 год**.

<a id="category-and-technology"></a>
## `category` и `technology`

`category` выбирает группу технологий, а `technology` — конкретные технологии. Для одного эффекта можно перечислить несколько значений одного типа.

Категории технологий определяются самой игрой в файлах `common/technology_tags/`, а конкретные технологии — в `common/technologies/`. Полный список категорий разберём отдельно, чтобы не смешивать справочник эффектов с перечнем технологических тегов.
