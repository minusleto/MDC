## Разное

Ванильные эффекты HOI4, не относящиеся ни к одной конкретной механике мода — сюда попадает всё, для чего нет отдельной тематической страницы.

### Переименование провинции/региона

| Эффект | Скоуп | Описание |
|---|---|---|
| `set_province_name` | Любой (берёт `id` явно) | Переименовывает конкретную провинцию: `set_province_name = { id = 6332 name = "Новое имя" }` |
| `set_state_name` | **Только скоуп state** (без `id`) | Переименовывает регион, в чьём скоупе вызван: `5 = { set_state_name = "Новое имя" }` или `every_owned_state = { limit = {...} set_state_name = "Новое имя" }` |

Переименование навсегда сохраняется в сейве и работает в мультиплеере. Ни один ванильный/модовый файл при этом не перезаписывается.
