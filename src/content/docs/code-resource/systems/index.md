# Системы MDC

Здесь находятся механики, которые не стоит смешивать с обычными эффектами и модификаторами.

- [Внутренние фракции](./internal-factions/) — работа с внутренними группами интересов.
- [Терроризм](./terrorism/) — радикализация и уровень террористической угрозы.
- [Картели](./cartels/) — сила и политическое влияние картелей.
- [Европейский союз](./european-union/) — ЕС и евроскептицизм.
- [Энергетика](./energy/) — энергетические объекты и связанные эффекты.


> **Важно:** раздел описывает игровые системы MDC. Сам код, который вызывается в ивентах, фокусах и решениях, находится в разделе **Эффекты**. Модификаторы для национальных духов, законов и других сущностей — в разделе **Модификаторы**.
