# НАТО

Этот гайд описывает механику НАТО, которая используется в предоставленных скриптах MDC: полное членство, статус Major Non-NATO Ally, Partnership for Peace (PfP), IPAP, Accelerated Dialogue, Membership Action Plan, ратификация, совместные операции и военные учения.

> Ниже указаны реальные script ID и условия из исходников. Названия локализаций могут отличаться от ID.

## Национальные духи и статусы

### `NATO_member` — член НАТО

Главный статус полного члена альянса. При добавлении духа страна также добавляется в глобальный массив `global.nato_members` и обновляет `global.NATO_dirty_update_var`.

Модификаторы духа:

| Модификатор | Значение |
|---|---:|
| `democratic_drift` | +0.02 |
| `defensive_war_stability_factor` | +0.03 |
| `war_support_factor` | +0.02 |

Членство автоматически отменяется, если страна больше не состоит во фракции или становится субъектом (`is_in_faction = no` / `is_subject = yes`).

При полноценном вступлении `NATO_join` также:

- добавляет `NATO_member`;
- добавляет страну в `NATO_Tech_Share`;
- присоединяет её к фракции НАТО;
- даёт взаимное улучшение отношений с членами;
- устанавливает взаимный military access;
- если у страны был `Major_Non_NATO_Ally`, этот дух снимается.

### `Major_Non_NATO_Ally` — Major Non-NATO Ally

Это отдельный статус, а не членство в НАТО. Он даёт:

- `democratic_acceptance = 20`;
- участие в группе обмена технологиями `Major_Non_NATO_Ally_Share`;
- взаимное улучшение отношений с членами НАТО;
- во многих механиках — военное взаимодействие с НАТО.

Статус не добавляет страну в `global.nato_members` и не присоединяет её к фракции НАТО.

### Другие связанные духи

В рассматриваемых скриптах также используются следующие идеи/статусы:

| ID | Назначение |
|---|---|
| `GENERIC_nato_pfp_idea` | статус Partnership for Peace |
| `GENERIC_nato_ipap_idea` | статус IPAP |
| `NATO_stanag_ratified_idea` | ратифицирован STANAG |
| `NATO_corps_north_idea` / `NATO_corps_south_idea` | приписка к северному/южному корпусу НАТО |
| `NATO_nrf_idea` | участие в NRF после завершения решения |
| `NATO_arf_idea` | участие в ARF после завершения решения |
| `NATO_ukraine_help` | помощь Украине от члена НАТО |
| `NATO_intervention_active` | активное участие в совместной операции/интервенции |
| `NATO_operation_active` | маркер операции для страны, инициировавшей совместную операцию |

Эти идеи не являются заменой `NATO_member`: например, PfP и IPAP доступны до полного членства.

#### `NATO_ukraine_help`

Требует `has_idea = NATO_member`. Даёт `industrial_capacity_factory = -0.2` — то есть это не бонус, а самим членством оплачиваемая «цена» помощи (условная нагрузка на промышленность от военной поддержки Украины).

#### `NATO_stanag_ratified_idea`

Выдаётся по завершении решения `NATO_ratify_stanag` (см. ниже) и снимается автоматически (`cancel`), если страна перестаёт быть `NATO_member`. Полный список модификаторов:

|---|---:|
| `personnel_cost_multiplier_modifier` | +0.25 |
| `production_factory_start_efficiency_factor` | −0.12 |
| `production_factory_efficiency_gain_factor` | −0.02 |
| `license_production_speed` | +0.12 |
| `army_org_factor` | +0.05 |
| `coordination_bonus` | +0.05 |
| `land_night_attack` | +0.12 |
| `max_planning_factor` | +0.09 |
| `recon_factor` | +0.07 |
| `planning_speed` | +0.07 |
| `naval_coordination` | +0.04 |
| `naval_detection` | +0.05 |
| `naval_night_attack` | +0.12 |
| `navy_org_factor` | +0.05 |
| `navy_max_range` | +0.3 |
| `night_spotting_chance` | +0.09 |
| `air_interception_detect_factor` | +0.05 |
| `air_escort_efficiency` | +0.05 |
| `air_night_penalty` | −0.12 |
| `air_accidents_factor` | −0.07 |

Заметный компромисс: серьёзный буст к координации/планированию/ночному бою на земле, море и воздухе, но за счёт просадки эффективности заводов при переключении производства (`production_factory_*`) и роста аварийности авиации.

#### `NATO_corps_north_idea` / `NATO_corps_south_idea`

Обе идеи требуют `has_idea = NATO_member` и снимаются, если членство потеряно. Модификаторы одинаковы для обеих (отличается только регион приписки):

| Модификатор | Значение |
|---|---:|
| `army_org_factor` | +0.08 |
| `coordination_bonus` | +0.05 |
| `max_planning_factor` | +0.03 |
| `recon_factor` | +0.05 |
| `planning_speed` | +0.03 |

#### `NATO_nrf_idea` (NATO Response Force)

Требует `NATO_member`, снимается (`cancel`), если членство потеряно **или** страна не воюет — то есть это чисто военная идея, активная только пока идёт война.

При добавлении (`on_add`) создаётся шаблон дивизии «NATO Response Force» (10 линейных батальонов + артиллерия, разведрота и инженерная рота в поддержке) и сразу же создаются **2 такие дивизии** в случайных подконтрольных штатах (`start_experience_factor = 0.4`).

При снятии (`on_remove`) шаблон и юниты удаляются (`disband = no` — юниты не распускаются полностью, а передаются/остаются), а у США снимается флаг `NATO_nrf_mobilize`.

Модификаторы небольшие (это в первую очередь про готовые дивизии, а не про баффы):

| Модификатор | Значение |
|---|---:|
| `army_org_factor` | +0.01 |
| `coordination_bonus` | +0.01 |
| `max_planning_factor` | +0.01 |
| `recon_factor` | +0.01 |
| `planning_speed` | +0.01 |

#### `NATO_arf_idea` (Allied Reaction Force)

Устроена так же, как NRF, но меньше по масштабу: шаблон дивизии «Allied Reaction Force» (4 линейных батальона + артиллерия, разведка и инженеры в поддержке), создаётся **1 дивизия** вместо двух. Модификаторы такие же, как у NRF (см. таблицу выше). При снятии снимается флаг `NATO_arf_mobilize` у США.

#### Скрытые идеи операций

`NATO_intervention_active` и `NATO_operation_active` — служебные маркеры (не показываются в интерфейсе идей страны напрямую как обычные бонусы). Обе снимаются, как только страна перестаёт воевать (`cancel = { has_war = no }`), и обе дают одинаковый эффект:

```
surrender_limit = 0.25
```

То есть пока активна интервенция/операция, порог капитуляции противника снижен — победу в войне становится проще довести до конца.

## Как вступить в НАТО

Вступление построено как последовательная цепочка решений. Для обычного кандидата из Европы, Кавказа, Канады, США или Турции путь выглядит так:

**Accelerated Dialogue → Membership Action Plan → ратификация всеми членами → Join NATO**.

### 1. Accelerated Dialogue

Решение: `GENERIC_nato_accelerated_dialogue_decision`.

Кандидат должен:

- быть европейской страной, страной Кавказа либо иметь оригинальный тег `CAN`, `USA` или `TUR`;
- не иметь `NATO_member`;
- уже иметь `nato_ipap`;
- для Беларуси (`BLR`) не иметь `BLR_neutrality_politic`;
- не иметь идею `the_military`;
- не иметь ни одного из `defence_00`, `defence_01`, `defence_02`;
- не находиться под восточным влиянием выше порога 10 со стороны SOV, CHI или PER.

После завершения страна получает флаг `nato_accelerated_dialogue`. Само решение отправляет событие лидеру НАТО (`generic_nato.12`).

### 2. Membership Action Plan

Решение: `finish_NATO_membership_action_plan`.

Основные требования:

- нет войны;
- страна подходит по географии/исключениям НАТО;
- не состоит во фракции;
- добавленная ею мировая напряжённость меньше 10;
- нет `the_military`;
- нет `defence_00`, `defence_01`, `defence_02`;
- нет `police_01`;
- нет тяжёлых уровней коррупции: `paralyzing_corruption`, `crippling_corruption`, `rampant_corruption`, `unrestrained_corruption`, `systematic_corruption`.

Для `BLR` также требуется отсутствие `BLR_neutrality_politic`.

После решения страна получает `NATO_Accession_Voting` и попадает в `global.NATO_Accession_Candidates`.

### 3. Ратификация членами НАТО

Решение члена НАТО: `ratify_country_accession`.

Каждый действующий член НАТО должен проголосовать за кандидата. За одну ратификацию тратится **20 political power**, а страна получает флаг вида `NATO_Ratified_@FROM`.

AI сильнее склоняется к ратификации, если:

- растёт напряжённость, создаваемая SOV;
- кандидат и член одновременно состоят в ЕС;
- у кандидата есть NATO member в первых позициях его `influence_array`;
- мнение о кандидате выше 199.

AI резко неохотно ратифицирует кандидата при высоком положительном отношении к SOV или низком собственном отношении к кандидату. Если кандидат находится в войне, для AI действует `-9999`.

Для ряда исторических стран есть отдельный сильный AI-бонус: LAT, LIT, EST, ROM, SLO, SLV, BUL, ALB, CRO, MNT, FYR, UKR, SWE и FIN.

### 4. Финальное вступление

Решение: `join_NATO`.

Оно становится доступно, когда **все существующие члены `global.nato_members` ратифицировали кандидата**.

После этого выполняется `NATO_join`, который:

1. устанавливает взаимные отношения и military access;
2. добавляет `NATO_member`;
3. добавляет `NATO_Tech_Share`;
4. присоединяет страну к фракции НАТО;
5. снимает `Major_Non_NATO_Ally`, если он был.

Если `can_join_NATO = no`, `NATO_join` вместо полного членства направляет страну в `Major Non-NATO Ally`, если этот статус ещё не установлен.

## Приглашение в НАТО (обходной путь через события)

Помимо долгой цепочки решений выше, есть параллельный, более быстрый путь — через прямое приглашение. Он не требует ни PfP, ни IPAP, ни Accelerated Dialogue, ни ратификации всеми членами: решение принимает единолично США.

**Кандидат (запрос) → США решают (событие NATO.14) → кандидат решает (событие NATO.9) → уведомление США (NATO.10 / NATO.11)**

1. **Запрос от кандидата.** Страна каким-то образом (сам механизм запроса не входит в предоставленные файлы — судя по локализации, это отдельное решение `become_NATO_aspirant`) сообщает США о желании вступить.
2. **NATO.14 — США решают, приглашать ли.** Событие приходит США, `FROM` = страна-заявитель.
   - **Принять** (`NATO.14.a`): `+25 political power`, через 6 часов заявителю отправляется приглашение `NATO.9`. AI США охотнее соглашается (`+25` к шансу), если Украина находится под сильным западным влиянием (`UKR_west_strengthened`/`UKR_west_dominant`).
   - **Отказать** (`NATO.14.b`): `-25 political power`, заявителю уходит новость-отказ `NATO.15`. Базовый AI-шанс на отказ — всего `1` (США почти всегда соглашаются рассмотреть заявку).
3. **NATO.9 — приглашение кандидату.** Текст: «Соединённые Штаты Америки и их союзники просят нас вступить в НАТО».
   - **Согласиться** (`NATO.9.a`): сразу `NATO_join = yes` (минуя всю цепочку ратификаций!), ставится флаг `has_joined_NATO_by_event`, США скрыто получает `NATO.10`. AI охотнее соглашается на выборах (`+70`) или если это Вьетнам при существующем Китае (`+70`); шанс обнуляется, если страна — субъект Китая или коммунистическая.
   - **Отказаться** (`NATO.9.b`): `+50 political power`, США получает `NATO.11`. AI охотнее отказывается без выборов (`+70`); шанс принудительно обнуляется для конкретных стран Балтии/Балкан (EST, LAT, LIT, SLO, SLV, ROM, BUL, ALB, CRO) — они по сценарию никогда не отказываются от приглашения.
4. **NATO.10 / NATO.11 — реакция США.** Просто уведомления: при согласии — взаимный `add_opinion_modifier = NATO_member_modifier`, при отказе — `recent_actions_negative`.

:::note
Этот путь полностью обходит проверки по географии, коррупции, милитаризации и т.д., которые обязательны для «долгого» пути через решения — раз США решили пригласить, а страна согласилась, вступление происходит мгновенно.
:::

## Partnership for Peace (PfP)

Решение: `become_NATO_pfp_member`.

Оно доступно странам той же географической группы, что и основной путь в НАТО: Европа, Кавказ, Канада, США или Турция, если у страны нет `NATO_member`, `nato_pfp` / `GENERIC_nato_pfp_idea` и нет `nato_ipap` / `GENERIC_nato_ipap_idea`.

Стоимость — **100 political power**, повторное использование — через **90 дней**.

Решение отправляет событие `generic_nato.1` лидеру НАТО. Для AI базовый шанс равен 1, с большим бонусом для демократических стран.

## IPAP

### Заявка

Решение: `GENERIC_nato_ipap_application_decision`.

Требования:

- подходящая география;
- нет `NATO_member`;
- уже есть `nato_pfp`;
- страна не состоит во фракции;
- добавленная напряжённость меньше 15;
- нет `the_military`;
- нет `defence_00`, `defence_01`, `defence_02`;
- SOV, CHI и PER не должны иметь влияние выше 10;
- выполняется проверка `nato_pfp_accept_tt`.

После подачи страна получает `NATO_ipap_Voting` и попадает в `global.NATO_ipap_Candidates`.

### Ратификация IPAP

Решение члена НАТО: `ratify_country_ipap`.

Каждый член тратит **20 political power** и устанавливает флаг `ipap_ratified_@FROM`.

AI учитывает мнение о кандидате, напряжённость от SOV, совместное членство в ЕС и наличие NATO member среди первых элементов `influence_array` кандидата.

### Получение IPAP

Решение кандидата: `GENERIC_nato_ipap_decision`.

Нужно, чтобы **все члены `global.nato_members`** установили `ipap_ratified_@ROOT`.

После этого страна получает `GENERIC_nato_ipap_idea`, флаг `nato_ipap`, military access с членами НАТО и взаимный opinion modifier `ipap_status`. PfP при этом снимается.

## Major Non-NATO Ally

Есть два основных пути получить статус.

### Автоматический fallback

`NATO_join` и `NATO_join_via_event` при `can_join_NATO = no` могут вызвать `NATO_major_non_nato_ally_join`.

Этот scripted effect выдаёт:

- `Major_Non_NATO_Ally`;
- флаг `Major_Non_NATO_Ally`;
- `Major_Non_NATO_Ally_Share`;
- взаимные отношения с членами НАТО.

### Самостоятельная заявка

Решение: `NATO_apply_to_become_major_non_nato_ally`.

Требуется:

- демократическое правительство;
- `gdp_total > 350` (через `350_total_gdp_tt`);
- ещё нет `Major_Non_NATO_Ally`;
- при существующем демократическом лидере НАТО его мнение о стране должно быть **> 100**;
- если США не подходят как лидер, аналогичная проверка идёт по другому лидеру НАТО.

Решение стоит **100 political power**.

При получении статуса страна получает также гарантию от лидера НАТО и military access с членами НАТО.

## Военные механики НАТО

### Совместная операция

Решение: `NATO_joint_operation`.

Стоимость — **125 political power**.

Доступно члену НАТО, который находится в наступательной войне, если нет активной операции и не действует глобальный cooldown.

При запуске невоюющие члены НАТО (включая подходящих субъектов членов) получают событие `NATO_rework.8`. На 365 дней ставится `NATO_intervention_cooldown`.

**Что происходит в `NATO_rework.8`** (получает каждый приглашённый член):

- **Принять** (`.8.a`): страна получает `NATO_intervention_active`, объявляет войну (`puppet_wargoal_focus`) всем врагам инициатора, и получает событие `NATO_rework.9` (простое подтверждающее уведомление). AI **по умолчанию не согласен** (`base = 0`), но шанс резко растёт при исторических привязках — например, `+500`, если страна это Польша/Англия/США и воюет с Ираком, или Франция/Англия/Норвегия/Канада/США и воюет с Ливией; также `+25` при наличии нефтяных интересов у противника инициатора (фракция `fossil_fuel_industry` + враг добывает нефть), `+5` за морскую промышленность, `+15` за оборонную промышленность, `+20` за фракцию военных.
- **Отказаться** (`.8.b`): без последствий для войны. AI охотнее откажется (`+50`), если у инициатора и так уже хорошее мнение о враге инициатора; `+25` при изоляционистских идеях (`intervention_isolation`, `intervention_local_security`); `+25` при `has_war_support < 0.5`; `+25` при низких уровнях расходов на оборону (`defence_00/01/02`).

### Требование вмешательства

Решение: `demand_alliance_intervention`.

Доступно `Major_Non_NATO_Ally`, находящемуся в войне при surrender progress > 0.7.

Стоимость — **125 political power**. Всем членам НАТО отправляется событие `NATO_rework.7`, а инициатор получает `NATO_intervention_active`.

**Что происходит в `NATO_rework.7`:** та же логика объявления войны врагам инициатора, что и в `.8.a` (accept-опция), но проще по AI: базовый шанс `25`, и резко (`factor = 100`) выше для США — то есть в этом сценарии именно США с высокой вероятностью откликаются первыми.

### Военные учения

Решение: `start_military_exercises_with_NATO`.

Доступно странам с:

- `Major_Non_NATO_Ally`;
- `NATO_member`;
- `GENERIC_nato_ipap_idea`.

Нужно иметь более 49 command power. В качестве цели выбирается союзник, который либо является США, либо соседствует с инициатором; цель не должна находиться в войне.

Запускается событие `NATO_rework.1`.

**Событийная цепочка учений:**

1. **`NATO_rework.1`** — инициатор выбирает тип учений (три варианта на выбор игрока, не через ai_chance):
   - **Сухопутные** → `NATO_rework.2` цели (опция `.c` — морские — доступна только если у обеих сторон есть прибрежный штат).
   - **Воздушные** → `NATO_rework.3`.
   - **Морские** → `NATO_rework.4` (доступна только при `is_coastal` у обеих сторон).

   Все три события отправляются не самой цели, а **союзнику союзника** (`FROM.FROM`) — то есть в цепочку добавлен посредник.

2. **`NATO_rework.2` / `.3` / `.4`** — цель соглашается или отказывается:
   - **Согласиться**: обе стороны получают `+15` к соответствующему опыту (`army_experience`/`air_experience`/`navy_experience`), флаг `recent_nato_exercises` на 360 дней, и таймированную идею (`recent_nato_army_exercises` — 180 дней; `recent_nato_air_exercises`/`recent_nato_navy_exercises` — 240 дней). Инициатор получает уведомление `NATO_rework.5`.
   - **Отказаться**: инициатор получает уведомление `NATO_rework.6`.

Флаг/идея «недавние учения» блокируют повторный запуск — решение проверяет их отсутствие и у себя, и у цели.

## STANAG

Решение: `NATO_ratify_stanag`.

Доступно члену НАТО без одной из идей `defence_00`, `defence_01`, `defence_02`.

Стоимость — **250 political power**, длительность — **1280 дней**.

После завершения добавляется `NATO_stanag_ratified_idea` и применяется `personnel_cost_multiplier_modifier = 0.25`.

## NRF и ARF

### NRF

`NATO_nrf_start` запускается членом НАТО во время войны.

Не может использоваться USA, GER, FRA, ENG и SOV. Также проверяется отсутствие уже активного `NATO_nrf_idea` и флага `NATO_nrf_mobilize` у США.

Стоимость — **100 political power**. После завершения добавляется `NATO_nrf_idea`.

### ARF

`NATO_arf_start` работает аналогично, но стоит **50 political power** и имеет более короткий срок решения.

После завершения добавляется `NATO_arf_idea`.

## Как выйти из НАТО

Решение: `leave_NATO`.

Стоимость — **100 political power**.

Оно доступно при `NATO_member` и вызывает `NATO_leave`.

При выходе:

- снимается `NATO_member`;
- страна удаляется из `NATO_Tech_Share`;
- страна выходит из фракции;
- если это был лидер, лидерство передаётся другому члену;
- удаляются взаимные NATO opinion modifiers;
- снимается military access;
- членам НАТО добавляется отношение `left_nato`.

AI в целом склонен выводить из НАТО недемократические страны, но для отдельных стран есть специальные правила. Например, для TUR, EST, LAT, LIT, HUN, NOR, GER, GRE, ITA, DEN, CAN и SPR прописаны отдельные исключения и условия.

## Новостные уведомления о смене статуса

Помимо самих решений, вступление/выход сопровождаются событиями-уведомлениями для остальных стран (в основном чисто информационные, без выбора влияющего на игру):

| Событие | Когда приходит | Кому |
|---|---|---|
| `NATO.7` | Страна подала заявку/стремится к членству | Странам-членам НАТО |
| `NATO.8` | Страна успешно вступила | Общая новость (`news_event`) |
| `NATO.13` (`major = yes`) | Официальная церемония принятия, после `join_NATO` | Общая крупная новость |
| `NATO.6` | Страна выходит из НАТО | Общая новость |
| `NATO.16` (`major = yes`) | Страна покидает НАТО — два варианта текста опции в зависимости от того, сама ли это страна, которая покидает (`original_tag = FROM`), или наблюдатель | Общая крупная новость |
| `NATO.17` | Автоматический авто-выход из-за смены курса (см. ниже) | Сама страна |

### Автоматический выход при смене политики

Событие `NATO_rework`-логики отдельно от решения `leave_NATO`: `NATO.17` срабатывает само (`is_triggered_only`), если у члена НАТО одновременно:

```
has_idea = NATO_member
has_elections = no
NOT = { has_government = fascism }
```

То есть страна свернула выборы, но при этом **не** стала фашистской (для фашистов, видимо, действует другая, более резкая логика исключения, не показанная в этом файле). Срабатывание `NATO.17` сразу вызывает `NATO_leave = yes` и скрыто рассылает новость `NATO.16` остальным странам.

## НАТО и CSTO: лимиты вооружённых сил

`NATO_CSTO_calculate_number_of_batallions` считает для европейских стран количество пехотных и танковых батальонов НАТО и ОДКБ.

Для каждой стороны проверяются пороги:

- **более 1000** учитываемых пехотных батальонов;
- **более 400** танковых батальонов.

При превышении европейские страны получают флаг `NATO_CSTO_agreement_breach_warning`, а лидер соответствующей организации получает миссию `NATO_CSTO_breach_mission`.

## Важное ограничение по географии

В полном членстве и связанных с ним процедурах используется условие:

- Европа;
- Кавказ;
- исключения `CAN`, `USA`, `TUR`.

Для `NATO_join` дополнительно прямо указано: только Европа, Северная Америка и Кавказ (плюс scripted exceptions) получают полное членство; остальные кандидаты направляются в Major Non-NATO Ally.

Поэтому наличие подходящей идеологии или хороших отношений с НАТО **само по себе не делает страну кандидатом на полное членство**.
