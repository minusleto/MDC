Triggers are conditions that check the game's state (as opposed to effects, which change it). The general concept is covered on the [Getting Started → Triggers](../getting-started/triggers/) page — this section is the detailed, category-by-category list.

## Sections

- [Basics](./basic/) — vanilla HOI4 triggers for beginners (NOT/AND/OR, comparison operators, has_stability, etc.)
- [Political](./political/) — ruling/coalition parties, ideological blocs, popularity thresholds
- [Economic](./economic/) — treasury, taxes, deficit/surplus, debt-to-GDP, economic blocs
- [Military](./military/) — border conflicts, doctrines, resistance, nuclear weapons, medals, NATO
