<a id="influence"></a>
## Influence

Affect the Foreign Influence system.

| Modifier | Description | Note |
|---|---|---|
| `foreign_influence_modifier` | Changes the effectiveness of influence actions | N/A |
| `foreign_influence_defense_modifier` | Decreases the effectiveness of influence actions against us | N/A |
| `foreign_influence_auto_influence_cap_modifier` | Increases auto-influence slots | N/A |
| `influence_coup_modifier` | Changes the chance of a successful coup | N/A |
| `foreign_influence_continent_modifier` | Changes influence effectiveness on other continents | Modifier is negative |
| `foreign_influence_home_continent_modifier` | Changes influence effectiveness on home continents | Modifier is negative |
| `foreign_influence_monthly_domestic_independence_gain_modifier` | Increases monthly independence gain | N/A |
| `foreign_influence_monthly_domestic_independence_gain_factor` | Factor applied to independence gain | N/A |

## World Tension & Diplomacy

Vanilla HOI4 modifiers.
