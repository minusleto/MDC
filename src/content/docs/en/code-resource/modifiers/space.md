## Space Modifiers

Affect the production speed of satellites and related hardware.

| Modifier | Description | Note |
|---|---|---|
| `spysat_production_speed_modifier` | Spy satellite production speed | N/A |
| `comsat_production_speed_modifier` | Communications satellite production speed | N/A |
| `gnss_production_speed_modifier` | Navigation satellite production speed | N/A |
| `killsat_production_speed_modifier` | Anti-satellite (ASAT) interceptor production speed | N/A |
| `olv_production_speed_modifier` | Orbital launch vehicle production speed | N/A |
