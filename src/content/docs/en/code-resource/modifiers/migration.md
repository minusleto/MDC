## Migration Modifiers

Affect population migration.

| Modifier | Description | Note |
|---|---|---|
| `migration_rate_value_factor` | Modifier to increase/decrease the amount of net migration into your country | N/A |
| `base_migration_rate_value` | Base value of the migration rate | N/A |
| `maximum_migration_rate_value` | Maximum value of the migration rate | N/A |
| `migrant_workforce_modifier` | Changes the share of migrant workers | N/A |
| `maximum_migrant_workforce_percent_modifier` | Changes the maximum share of migrant workers | N/A |
