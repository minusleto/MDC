# Culture & Tourism

## Modifiers

| Modifier | Effect | Unit |
|---|---|---|
| `state_tourism_modifier` | Tourism modifier in a state | % |
| `country_tourism_modifier` | Tourism modifier in a country | % |
| `state_culture_modifier` | Culture modifier in a state | culture amount |
| `country_culture_modifier` | Culture modifier in a country | culture amount |
| `culture_defence_modifier` | Defence against culture | % |
| `tourism_workers_modifier` | Tourism workforce modifier | % |
| `tourism_productivity_modifier` | Tourism industry productivity modifier | % |
| `tourism_tax_modifier` | Tourism industry tax modifier | % |

> Scope and exact calculation rules are described according to the supplied MDC notes. Usage examples inside `modifier = { ... }` can be added later.
