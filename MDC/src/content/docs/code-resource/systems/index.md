## Системы

Здесь описаны игровые механики MDC, у которых нет отдельного скриптового API — только логика самой системы.

- [Контртерроризм](./terrorism/) — радикализация и уровень террористической угрозы для стран Counter Terror

Скриптовые эффекты и модификаторы систем экономики, влияния, внутренних фракций, энергетики, картелей, ЕС и терроризма (со стороны его сторонников) вынесены в раздел [Эффекты](../effects/), так как именно там документируется весь их код.
